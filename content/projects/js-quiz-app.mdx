4지선다 퀴즈를 풀고 틀린 문제를 다시 확인할 수 있는 웹 앱입니다.


## 맡은 역할


Vue 기반 퀴즈 웹 앱을 개발했습니다.


## 개발·활동 내용


JSON 파일의 문제를 읽어 순서를 섞어 표시하고, 정답 수와 오답을 관리하도록 구성했습니다. 문제 시작·재시작과 오답 복습 흐름을 구현했습니다.


## 결과


성과: 문제 표시·채점·오답 복습 기능 구현
