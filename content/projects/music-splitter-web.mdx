Spring Boot와 FastAPI를 연결해 음원 업로드부터 AI 분리 결과 다운로드까지 구현한 학부 프로젝트입니다.


## 본인 역할과 구현


웹·API 연동과 음원 분리 기능 개발을 담당했습니다.


Spleeter의 5개 음원 분리 모델을 활용하고 Spring Security 기반 회원가입·로그인을 구현했습니다. 웹 요청과 Python 기반 AI 처리 서버를 연결했습니다.


성과: 업로드 → 5개 음원 분리 → 결과 다운로드 흐름 구현


## 검증 범위


로컬 실행 환경의 웹 서비스입니다. 기존 Spleeter 모델을 활용했으며 자체 분리 모델 학습이나 상용 서비스 운영 실적으로 제시하지 않습니다.
