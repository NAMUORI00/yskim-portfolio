사용자가 음원을 올리면 보컬과 악기 등 5개 음원으로 분리하고 결과를 내려받을 수 있는 웹 서비스를 구현했습니다.


## 맡은 역할


웹 화면과 서버 API 연결, AI 음원 분리 기능 연동, 회원가입·로그인 기능을 개발했습니다.


## 구현한 기능


Spring Boot 웹 서버와 Python 기반 FastAPI 서버를 연결해 파일 업로드부터 AI 처리, 결과 다운로드까지 하나의 흐름으로 구성했습니다.


기존 Spleeter 모델로 음원을 5개로 분리하고, Spring Security로 회원가입·로그인을 구현했습니다.


## 결과와 실행 환경


성과: 음원 업로드 → AI 분리 → 결과 다운로드 구현


학부 프로젝트로 로컬 환경에서 실행하는 웹 서비스를 개발했습니다. 기존 AI 모델을 실제 웹 기능으로 연결한 경험입니다.


## 사용 기술


Java · Spring Boot · Spring Security · Python · FastAPI · Spleeter
