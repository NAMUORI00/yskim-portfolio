장치에서 수집한 센서 데이터를 저장하고 웹 화면에서 확인하는 스마트홈 모니터링 시스템을 개발했습니다.


## 맡은 역할


센서 데이터 수집 펌웨어, 데이터베이스 저장과 웹 모니터링 화면을 구현했습니다.


## 개발·활동 내용


Arduino에서 센서 데이터를 수집하고 PHP·MySQL을 활용해 데이터 저장과 화면 표시를 연결했습니다.

## 사용 기술


Arduino, PHP, MySQL
