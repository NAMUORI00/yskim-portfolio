## 맡은 역할


Python 기반 데이터 전처리와 시각화를 담당하고 팀 분석 결과를 제안서로 정리했습니다.

관광·소비 데이터를 정리하고 시각화해 팀의 분석과 배치 제안에 활용했습니다. 팀원들이 수행한 군집화·예측 분석 결과와 함께 배치 제안서를 작성했습니다.
