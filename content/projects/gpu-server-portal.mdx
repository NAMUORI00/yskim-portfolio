3개 연구실이 함께 쓰는 DGX H200 GPU 서버를 연구원별 작업 공간으로 나누는 일을 주도하고 웹 포털을 개발했습니다.


## 맡은 역할

분할 방식 설계와 웹 포털 개발을 주도하고, 한국인과 외국인 연구원이 같은 절차로 서버를 쓸 수 있도록 한국어와 영어 운영 설명서를 만들었습니다.


## 결과

성과: 현재 3개 연구실이 이 방식으로 서버를 나눠 사용

연구원마다 작업 공간을 나눠 쓰는 방식이 3개 연구실에 자리 잡았습니다. 내부망 구성과 연구원들의 LLM 활용도 함께 지원했습니다.
