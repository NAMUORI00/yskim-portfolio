질문의 특징에 맞는 검색 조합을 선택하는 RAG를 설계·구현하고 비교 실험을 수행했습니다.


## 본인 역할과 구현


연구 방법 설계, 구현, 비교 실험과 제1저자 논문 작성을 담당했습니다.


단어 일치·의미 유사도·정보 간 관계를 활용하는 검색 결과를 결합했습니다. 검색 조합의 사전 비교 결과를 활용해 검색 비율 결정용 추가 LLM 호출을 대체하고 공개 자료에서 기존 검색 방식과 비교했습니다.


별도 운영 시스템에서는 관측 정보, 문서 근거, AI 설명, 운영자 승인과 실행 결과 확인 흐름을 웹·서버로 연결했습니다.

## 검증 범위


승인·실행 흐름은 시뮬레이션 환경에서 검증했습니다. 실제 농장 자동제어 실적으로 제시하지 않습니다. 소스 저장소는 비공개입니다.
