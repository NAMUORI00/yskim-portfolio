키워드, 벡터, 그래프 검색을 질문 유형별로 미리 정한 가중치로 결합해 질문마다 LLM을 추가 호출하던 과정을 없애고, 운영자 승인 후에만 제어를 실행하는 AI 에이전트용 MCP 서버를 구현했습니다.


## 맡은 역할

연구 방법 설계, 검색 기능과 MCP 서버 구현, 기존 방식과의 비교 실험, 제1저자 논문 작성을 담당했습니다.


## 구현한 기능

키워드, 벡터, 그래프 검색을 질문 유형별로 미리 정한 가중치로 결합해 질문마다 LLM을 추가 호출하던 과정을 없앴습니다. 그래프 근거 신뢰도가 낮거나 설정 검증에 실패할 때는 안전한 검색으로 전환하도록 구성했습니다.

AI 에이전트용 MCP 서버에서는 조회 도구와 제어 도구를 나누고, 운영자 승인 후에만 제어를 실행하며 모든 요청을 기록합니다.


## 비교 실험과 운영 검증

성과: nDCG@10 0.72→0.90, 엣지 장비 응답 시간 약 12% 단축, KCI 제1저자 게재

세 검색을 같은 비율로 결합한 방식과 비교해 nDCG@10을 0.72에서 0.90으로 높였고, 질문마다 LLM으로 가중치를 정하던 방식보다 엣지 장비 응답 시간을 약 12% 줄였습니다. 운영 지원 시스템에서는 관측 정보, 문서 근거, AI 설명, 운영자 승인, 실행 결과 확인을 연결했습니다. 이 운영 흐름은 시뮬레이션 환경에서 검증했습니다.


## 사용 기술

Python, RAG, MCP, FastAPI, Docker, GitHub Actions
