pi, dsh, Claude Code, Codex, Cursor 프록시 같은 코딩 에이전트를 함께 쓰며, 에이전트가 맡은 일을 사람이 검토하고 승인할 수 있는 하네스 도구를 만들어 개발에 활용합니다.


## 하네스 도구와 반복 작업 자동화

외부 AI의 검토를 사람 승인 아래 주고받는 Codex 플러그인, 노션을 에이전트의 기억 저장소로 쓰는 MCP 서버, 영상 스트리밍 서버 설치 스크립트를 만들었습니다. 이 포트폴리오도 콘텐츠와 코드를 Git에서 관리하고 Cloudflare 배포로 연결합니다.


## 더 탐구하고 싶은 내용

에이전트 사이의 역할 분담 기준과 작업 맥락 저장 구조를 다듬고, 자동화의 실행 상태와 변경 근거를 남겨 사람이 검토할 지점을 분명하게 드러냅니다.
