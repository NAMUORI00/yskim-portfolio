외부 서버 없이 기기 안에서 동작하는 온디바이스 AI와, 여러 연구실이 함께 쓰는 GPU 서버를 연구원별 작업 공간으로 나눠 쓰는 환경을 다룹니다. llama.cpp와 양자화 모델을 이용한 로컬 실행, PyTorch와 CUDA 기반 학습 환경, 설정 파일을 통한 실험 관리를 경험했습니다.


## 모델을 실행하고 작업 공간을 나누는 일

3개 연구실이 함께 쓰는 DGX H200 GPU 서버의 연구원별 작업 공간 분할을 주도하고 웹 포털을 개발해, 현재 3개 연구실이 그 방식으로 서버를 사용하고 있습니다. 온디바이스 환경에서는 Pixel 7 기반 안드로이드 에뮬레이터에서 인터넷 권한 없이 동작하는 의료 질의응답 앱을 구현했습니다.


## 더 탐구하고 싶은 내용

기기 메모리 제약에 맞춘 양자화 모델 실행 구성을 다듬고, 공용 GPU 서버의 작업 환경 관리를 자동화합니다.
