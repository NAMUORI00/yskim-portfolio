개인 PC와 GPU 서버에서 모델을 실행하고 학습·평가 조건을 관리하는 방법을 탐구합니다. llama.cpp와 양자화 모델을 이용한 로컬 실행 환경, PyTorch·CUDA 기반 학습 환경, 설정 파일을 통한 실험 관리를 경험했습니다.

## 모델을 실행하고 실험 조건을 관리하는 작업

장비에 맞는 모델 실행 환경을 구성하고, 설정을 기록해 실험을 이어갈 수 있도록 정리했습니다. 모델을 연결하는 작업뿐 아니라 실행 과정과 결과를 확인하는 흐름에도 관심이 있습니다.

## 더 탐구하고 싶은 내용

장비의 메모리와 연산 제약에 맞는 실행 구성을 검토하고, 반복 실험의 설정과 결과를 비교하기 쉽게 관리하고자 합니다.
