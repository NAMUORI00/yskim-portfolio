# Notion 연동 종료와 Git 관리 전환

2026-10-01부터 포트폴리오의 편집 원본은 Git 저장소입니다.

- 기존 Notion 콘텐츠를 옮긴 `content/`와 정적 이미지를 보존합니다.
- Notion 자동 동기화 워크플로, 가져오기 스크립트, 관련 패키지와 미디어 프록시를 제거했습니다.
- 이전 변환 로직은 Git 이력에서 확인할 수 있습니다.
- 포트폴리오 관리 페이지와 하위 데이터베이스는 Markdown·CSV 전체 내보내기(133개 파일)를 보존한 뒤 2026-10-01 휴지통으로 이동했습니다. 블로그 관리 페이지는 유지합니다.
- 저장소의 `main` push를 기존 Cloudflare Pages 연동이 빌드하고 배포합니다.
- GitHub 저장소의 NOTION_TOKEN secret과 NOTION_* 데이터베이스 변수 10개를 제거했습니다. Notion 자격 증명은 빌드와 실행에 필요하지 않습니다.
